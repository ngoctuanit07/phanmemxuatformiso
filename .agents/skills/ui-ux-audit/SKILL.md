# Ui Ux Audit — V5

1. Read AGENTS, active task, existing design docs; identify product, personas, key flows, stack and routes. Use scoped Graphify query only if useful.
2. Inspect representative screens in browser at desktop/tablet/mobile widths (e.g. 1440, 768, 390 CSS px). Capture baseline; if unavailable inspect relevant templates and label visual findings unverified. Use safe dev/test accounts, no real customer data.
3. Audit navigation, hierarchy, typography, spacing, forms, tables, feedback, mobile overflow, keyboard/focus, contrast, accessible names, error/loading/empty states, and task completion.
4. Research relevant current official design guidance and 3–5 comparable interfaces if accessible; log URLs, dates, observed patterns, limitations in DESIGN_RESEARCH. Separate trend from requirement; don't copy assets.
5. Record issue ID, screen, evidence, severity, user impact, suggested improvement, effort and verification in UI_AUDIT. Prioritize critical accessibility and workflow blockers. No code modification in audit-only mode.
