# Marketplace Release Automation

Read V7 marketplace rules and current official marketplace requirements. Verify original author eligibility, rejection history and no resubmission of disallowed hard-rejected items. Keep private secrets, logs, caches, .git, .env and customer data out of archives. Test installation in sandbox with fresh DB and appropriate requirements. Ensure buyer English docs reflect real functions; demo isolated with no production data; license/attribution for assets. Preflight release ZIP and document reasoned GO/NO-GO. No automatic upload, deploy or paid action.
