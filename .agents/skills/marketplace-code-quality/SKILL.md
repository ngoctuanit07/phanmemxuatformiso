# Marketplace Code Quality — V9

- First verify source quality, formatting, naming, docblocks where useful, dependency provenance and commercial differentiation.
- Validate controllers, routes, models, views and frontend UI against actual supported framework and project standards.
- Require security, installation, documentation, clean packaging, licensing, compatibility and demo checks separately.
- Use official CodeCanyon and Codester current public guidelines; distinguish stated requirements from Jacklabs internal QA suggestions.
- Never claim formal marketplace approval or guarantees; rejection can occur for non-formatting reasons.
- Report evidence, severity, file path and next repair step.
