# Marketplace Rejection Diagnostics
1. Read AGENTS.md, V7_RULES.md, V7_MODES.md, REJECTION_CASE.md, submission history and prior audit.
2. Identify marketplace and item status; request screenshot/account-specific evidence if not available. Do not assume reason when no email.
3. Verify current rules using official sources. Distinguish policy from suggestions.
4. Cross-check rejection factors: originality/market saturation, UI/demo quality, completeness, packaging, docs, rights/license, security, clean install, item eligibility.
5. Rank hypotheses by evidence strength: Confirmed / Strong indicator / Hypothesis / Unknown. Do not assert guesses as fact.
6. Produce remedy list, effort, proof and test plan. Record status and official contact path.
7. For hard rejections, prohibit unchanged resubmission; determine whether a substantially different genuinely new offering is viable under marketplace rules.
8. Store next single action and checkpoint.
