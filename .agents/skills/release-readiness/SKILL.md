# Release Readiness — V5

1. Read roadmap, task state, design QA, feature matrix and relevant architecture decisions. Verify unresolved blockers against Git and actual code.
2. Check installation/update docs, supported environments, migration safety, license and third-party obligations, dependency/security checks, secrets, build/test results, UI accessibility and key workflows.
3. Identify commercial readiness gaps, packaging requirements and known limitations; only verify marketplace rules from current official sources if relevant.
4. Record PASS/FAIL/NOT_RUN for each gate in RELEASE_READINESS.md. Recommend ready/not ready/conditional with evidence. No publishing, deployment, payments or production migration without explicit authorization.
