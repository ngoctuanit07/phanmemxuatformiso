# Marketplace evidence and checklist
Sources checked 2026-11-22; recheck at release. Category-specific rules override this summary.
- Envato code preparation: https://help.author.envato.com/hc/en-us/articles/360000471583-Code-Item-Preparation-Technical-Requirements — organized editable validated code, rights to assets, English buyer documentation in HTML or PDF and publicly accessible online, ZIP preparation.
- Envato common rejection factors: https://help.author.envato.com/hc/en-us/articles/360000536823-Common-Rejection-Factors-for-Code-Items — secure readable PHP, abstraction, usability/customization, documentation, differentiation.
- Envato category requirements: https://help.author.envato.com/hc/en-us/sections/360000089563-Code-Item-Requirements — check actual category (e.g. NodeJS) and applicability.
- Codester upload: https://www.codester.com/info/upload — organized code, naming/indentation, documented code, English item/docs; ZIP with docs, 800x400 preview, 200x200 icon, screenshots ZIP, description, demo and profile requirements.
- Codester rights: https://support.codester.com/hc/en-us/articles/115000018789-What-items-are-allowed-to-be-sold-on-Codester
- OWASP ASVS: https://asvs.owasp.org/ — stable 5.0.0; internal security reference, not marketplace certification.

Internal release checklist (not all platform mandates): clean install/upgrade, rollback plan, license inventory, SBOM where useful, dependency audit, security tests, demo with synthetic data, buyer support documentation, accessible/responsive UI, reproducible archive, no secrets, no debug output, version/changelog. Keep an evidence table: platform/category | official URL | date checked | requirement | applicable? | status | evidence | next action. No guarantee of approval. Do not assume seller enrollment is open. Verify relevant submission conditions before release.
