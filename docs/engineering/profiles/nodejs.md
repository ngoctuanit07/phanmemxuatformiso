# nodejs engineering profile
Detect Express/Nest/Fastify and JS/TS version. Route middleware/guards and object-level checks; schema validation (existing Zod/Joi/class-validator/framework schema); reject unexpected writable fields; map DTOs explicitly. Express error middleware and async propagation according to major version; Nest filters/pipes/guards; Fastify schema/error handler. Central safe error mapping and request IDs. ORM scoped queries and transaction APIs; parameterized raw SQL. Avoid prototype pollution, unbounded body sizes, unsafe redirects, SSRF, unsafe child_process and dynamic evaluation. Cookies/CSRF or bearer tokens as applicable, explicit CORS, rate limits. Graceful shutdown, timeouts, health checks. Use configured ESLint/Prettier/tsc/test/build, npm audit when authorized; avoid npm audit fix --force. Test promise rejection, ownership and transaction rollback. Lockfiles and supported node version.
These are internal engineering controls, not claims of marketplace-specific mandatory framework patterns.
