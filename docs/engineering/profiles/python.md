# python engineering profile
Detect Django/FastAPI/Flask and versions. Use framework validation (forms/serializers/Pydantic as appropriate), explicit authorized fields, permission dependencies and scoped ORM queries. Parameterize SQL; use atomic transaction APIs. Central exception handlers; never broad catch-and-pass; preserve exception cause and avoid stack traces in public responses. CSRF/session configuration for cookie auth, safe template rendering, path/upload checks. Type hints and configured Ruff/Black/mypy/pytest or framework checks; dependency audit if authorized. Bound async work and external call timeouts; validate deployment settings and reproducible dependency installation.
These are internal engineering controls, not claims of marketplace-specific mandatory framework patterns.
