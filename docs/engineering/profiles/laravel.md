# laravel engineering profile
Verify Laravel/PHP version and installed packages. Route groups with auth/throttle and policies/gates; FormRequest rules and authorize where appropriate; validated()/safe() and explicit fields; never request()->all() to create/update. Eloquent fillable/guarded plus explicit write allowlist; hidden fields/resources; tenant-scoped bindings/queries and policies, no global-scope-only assumption. Service/use case for substantial workflows; DB::transaction with exception propagation, lockForUpdate where justified, unique constraints. Central exception configuration appropriate to Laravel version; report/render expected exceptions; local catch only recovery. Config/env separation, APP_DEBUG=false in production. Blade escaped output, CSRF for web forms, safe uploads/storage. Use existing Pint/PHPCS/PHPStan/Larastan and PHPUnit/Pest if configured; php artisan route:list in safe environment, feature tests for policies and validation. composer audit if authorized/network available. Avoid forcing repository around Eloquent. Verify installation on advertised PHP/DB/shared hosting versions.
These are internal engineering controls, not claims of marketplace-specific mandatory framework patterns.
