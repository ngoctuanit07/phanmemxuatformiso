# V5 — Mode router

| Mode | Scope | Skill / output |
|---|---|---|
| AUTO | Choose one evidence-backed, low-risk improvement | Relevant skill; state rationale |
| AUDIT | Read-only product/code/UI assessment | product-growth discovery or ui-ux-audit; no source edits |
| FEATURE | One requested feature | AGENTS workflow |
| COMMERCIAL | Competitor research, gap matrix; implement one only if requested | product-growth |
| REDESIGN | Audit, design system, one scoped UI batch | ui-ux-audit, design-system, ui-modernization, visual-qa |
| BUGFIX | Root cause, narrow fix, regression check | AGENTS workflow |
| OPTIMIZE | Measured performance improvement | performance |
| RESUME | Recover active task from state + Git + source | task-continuity |
| RELEASE | Verify readiness; do not publish | release-readiness |

## Execution contract
Respect explicit user scope. Read AGENTS and the current task record; do not load all skills. If a different task is active, preserve its record and explicitly note switching. Choose the smallest safe batch. For complex work record acceptance criteria, dependencies, risk, and next step. Save checkpoints on meaningful progress or interruption. Use Graphify when cross-module discovery warrants it, not for trivial edits. No paid calls, production changes or destructive actions without authorization. Report actual evidence, blockers and next action. AUDIT writes reports only if requested; otherwise respond without changing files. RELEASE is assessment, not deployment.
